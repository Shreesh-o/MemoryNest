Data Flow Diagram (DFD) — MemoryNest

Complete Multi-Level DFD Specification: Level 0 (Context), Level 1 (Main Processes), and Level 2 (Detailed Processes)

Level 0: Context Diagram
Level 0 shows the overall interaction between the MemoryNest system and the user. Users can upload documents, ask questions, request summaries, and manage events. MemoryNest provides search results, AI-generated answers, document summaries, and event notifications. It can also connect with Google Calendar and Gmail to support event management and email notifications.
Level 1: Main Processes
Level 1 presents the main processes of MemoryNest, including document uploading and processing, embedding generation and storage, semantic search using RAG, AI-based processing, and output generation. Document storage, ChromaDB, the knowledge graph, and SQLite help manage files, embeddings, relationships, and user information.
Level 2: Detailed Processes
Level 2 explains the steps involved in each major process. It begins with document uploading, text extraction, preprocessing, and chunking. The system then generates embeddings, stores them in the vector database, and updates the knowledge graph. When a user submits a question, the system retrieves relevant information and passes it to the Ollama language model to generate an answer or summary.
